# Microsoft Landing Page Clone

A frontend landing page inspired by the Microsoft website, built using **HTML5 and CSS3**.

This project was created as part of my journey to learn and practice frontend web development. I focused on recreating the structure, layout, styling, cards, navigation, and visual sections of a modern landing page.

> **Note:** Responsive design has not been implemented yet. I am currently learning responsive web design and plan to improve this project after learning media queries, Flexbox, CSS Grid, and mobile-first design.

## 🚀 Project Overview

The goal of this project was to practice building a complete webpage from scratch using HTML and CSS.

The page contains:

* Microsoft-style navigation bar
* Hero/banner section
* Product/service cards
* Business section
* Promotional sections
* Social media section
* Footer with multiple categories
